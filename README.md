A portfolio site for a biomaterials and sustainable product-design project — currently under construction.

## What it is

Ecofabriq is a product-design project about biomaterials and sustainability. This repo holds its portfolio page. The page itself is still a placeholder — a single "WIP" screen — while the write-up gets built out.

## Stack

Plain HTML and CSS. No build step, no dependencies.

## Run locally

```bash
python3 -m http.server
```

Then open the served `index.html` in a browser.

## Map

```
index.html   the entire site (currently a single WIP placeholder)
```
